# 🛠️ نظرة عامة على الأدوات والتقنيات المستخدمة

في هذا المشروع، نعتمد على مجموعة مختارة من الأدوات البرمجية والتسويقية التي تضمن تنفيذ العمل بكفاءة واحترافية، سواء في تطوير الموقع، إعداد المحتوى، أو تنفيذ حملات التسويق الرقمي.

---

## 💻 أدوات التطوير

| الأداة / التقنية       | الاستخدام الرئيسي                           |
|------------------------|----------------------------------------------|
| **React.js (v19)**     | لبناء واجهة المستخدم التفاعلية               |
| **Laravel (v12)**      | لتطوير الواجهة الخلفية وتوفير الـ APIs       |
| **Vite**               | لإدارة البناء السريع والتكامل بين Laravel وReact |
| **Inertia.js**         | للربط السلس بين الواجهتين الأمامية والخلفية  |
| **Tailwind CSS**       | لتصميم سريع ومتجاوب دون كتابة CSS يدوي       |
| **Git & GitHub**       | لإدارة الشيفرة المصدرية ومتابعة التقدم        |

---

## 🧠 أدوات المحتوى والتوثيق

| الأداة                 | الاستخدام                                    |
|------------------------|----------------------------------------------|
| **Notion / Google Docs** | لتنسيق وتحرير فصول الكتاب والمحتوى النصي    |
| **Markdown**            | لتوثيق المشروع في GitHub وصفحات الوثائق     |
| **ChatGPT / AI Tools**  | للمساعدة في توليد الأفكار والمحتوى الأولي    |
