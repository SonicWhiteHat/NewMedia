# 🎨 تصميم الموقع

تهدف واجهة الموقع إلى تقديم تجربة سلسة وجذابة للمستخدم، مع إبراز الهوية البصرية للمشروع وتقديم المحتوى التسويقي بشكل فعّال. يعتمد التصميم على مبادئ البساطة، الوضوح، والتفاعلية.

---

## 🖥️ الهيكل العام للموقع

| القسم                   | الوصف                                                             |
|--------------------------|------------------------------------------------------------------|
| **الصفحة الرئيسية**       | عرض موجز عن المشروع، دعوة للاكتشاف، زر دعوة للتسجيل أو تحميل الكتاب |
| **عن المشروع**          | شرح مختصر لرؤية المشروع وأهدافه التسويقية                       |
| **فصول من الكتاب**       | عرض مختارات من محتوى الكتاب الرقمي مع إمكانية التصفح أو التحميل     |
| **الدورة التدريبية**     | تفاصيل التسجيل، محتوى الدورة، الشهادات المقدمة                  |
| **المدونة**              | مقالات متجددة حول التسويق الرقمي، الأدوات، ونصائح الخبراء         |
| **اتصل بنا**             | نموذج للتواصل، الروابط الاجتماعية، والموقع الجغرافي              |

---

## 🎯 مبادئ التصميم المعتمدة

- استخدام **ألوان حديثة ومريحة** تعكس المجال الرقمي (مثل الأزرق والبنفسجي والأخضر).
- اعتماد **خطوط عربية وأجنبية واضحة** مثل: Cairo / Poppins.
- تصميم **متجاوب بالكامل** يعمل على جميع الأجهزة (موبايل، تابلت، كمبيوتر).
- توفير تجربة **Dark Mode** لتجربة تصفح مريحة.
- استخدام **Animations خفيفة** لجذب الانتباه دون تشتيت المستخدم.
- التركيز على **دعوات الإجراء (CTAs)** في كل قسم (تحميل، تسجيل، قراءة، ...).

---

## 🧩 الأدوات المستخدمة في التصميم

| الأداة              | الاستخدام                                       |
|---------------------|--------------------------------------------------|
| **Figma**           | تصميم النماذج الأولية للصفحات                    |
| **Tailwind CSS**    | إنشاء تصميم مرن وسريع بدون كتابة CSS معقد       |
| **Framer Motion**   | إضافة تحريكات سلسة للعناصر                      |
| **Lucide Icons**    | استخدام أيقونات بسيطة وواضحة                     |
