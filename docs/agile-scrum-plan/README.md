# 🧩 منهجية تخطيط سكرام لمشروع التسويق الرقمي

## 🚀 لماذا نستخدم سكرام؟

سكرام هو إطار عمل يساعدنا على تطوير المشروع بطريقة مرنة، متدرجة، وتشاركية، ويعتمد على تقسيم العمل إلى فترات زمنية قصيرة تُعرف بـ "سبرينتات"، مما يجعلنا قادرين على:

- اختبار الأفكار سريعًا
- تصحيح المسار في الوقت المناسب
- إشراك كل الأعضاء في دورة تطوير مستمرة

---

## 📅 الهيكل العام للسبرينتات

| الرقم | اسم السبرينت            | المدة     | الهدف الأساسي                           |
|-------|--------------------------|-----------|------------------------------------------|
| 1     | Sprint 1: البنية الأساسية | أسبوع     | إعداد هيكل المشروع، خريطة المحتوى، GitHub |
| 2     | Sprint 2: كتابة الفصل الأول | أسبوع     | كتابة أول فصل من الكتاب + نشره في الموقع |
| 3     | Sprint 3: واجهة الموقع     | أسبوع     | تصميم الواجهة الرئيسية وتجربة المستخدم   |
| 4     | Sprint 4: إطلاق النسخة الأولية | أسبوعين | اختبار تجربة المستخدم + تلقي ملاحظات   |

---

## 🧑‍🤝‍🧑 أدوار الفريق

| الدور              | المسؤوليات                                    |
|--------------------|-----------------------------------------------|
| Product Owner      | تحديد أهداف المحتوى، مراجعة الفصول            |
| Scrum Master       | تسهيل الاجتماعات، إزالة العقبات               |
| Developers         | بناء الموقع، تكامل الكتاب، تحسين الأداء       |
| Content Writers    | كتابة الفصول، مراجعة الجودة اللغوية           |
| UI/UX Designers    | تصميم تجربة المستخدم وبنية الصفحات           |
| QA & Testing       | اختبار جودة المحتوى والموقع                    |

---

## 🛠️ الأدوات المستخدمة في التخطيط

- **ClickUp**: لتخطيط المهام والسبرينتات
- **GitHub Projects**: لتتبع التقدم البرمجي
- **Google Docs / Notion**: لتنسيق الفصول ومراجعتها
- **Figma**: لتصميم الواجهة وتجربة المستخدم

---

## 📌 الاجتماعات الأساسية

| النوع           | الهدف                                      | التكرار     |
|----------------|---------------------------------------------|-------------|
| Sprint Planning | تحديد المهام والأولويات لكل سبرينت        | بداية كل سبرينت |
| Daily Standup   | متابعة التقدم والتحديات اليومية            | يوميًا       |
| Sprint Review    | عرض ما تم إنجازه وتلقي الملاحظات          | نهاية السبرينت |
| Retrospective   | تقييم السبرينت وتحديد فرص التحسين         | نهاية كل سبرينت |
